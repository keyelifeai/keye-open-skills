# 证据与品牌规则

## 品牌定制

只需企业品牌名称和主营产品即可开始定制。名称和产品信息进入品牌配置、每次任务快照、brief 和文章元数据；公司观点和术语使用当前品牌。适用于饲料、添加剂、养殖、育种、设备、技术服务等畜牧企业，不预设某一产品路线或物种。

输入品牌信息是选题和表达背景，不是有效性或合规证据。不得从名称推测配方、剂量、资质、效果或市场地位。初始配置不要求产品资料；文章需要具体产品主张时，另找产品专属证据。没有这类证据时删去主张或保留缺口，不阻止独立技术文章。

## 来源与台账

- `external_url`：真实访问过的公开网页，记录完整 HTTP/HTTPS URL 和可复核定位；不得带登录凭据或签名访问令牌。
- `user_document`：用户主动提供并授权本次只读研究的文件，记录可重新找到的文件路径和 `#章节或页码`。格式可为 Markdown、PDF 等；实际内容由可用阅读工具核验，脚本不解析或上传原文件。
- 风格范文不提供事实证据，不得进入台账。
- 所有来源均为 `review-required`。公开可读、公司自述或现有资料审批字段均不能替代本篇文章的审核。`do-not-use` 行和对应主张在交付前移除。
- 每个实质主张独立一行，准确记录来源、类别、公开使用判断、核验状态、支持类型及审核备注。备注关联矩阵 Evidence ID、利益冲突、更新检查与适用边界。
- `verified` 表示作者确实打开资料并核对主张，不是脚本验证，也不是批准发布。
- `direct-evidence` 与 `inference` 分开。保留对象、条件、日期、设计和不确定性。找不到或无法复核的来源不能支撑确定主张。

## 物种与研究质量

技能适用于各畜种及水产等养殖动物，不把示例物种变成限制。跨物种证据可用于比较和机制解释，但不能把单一物种的结果写成所有物种的结论。区分 mechanism、in-vitro、controlled-animal、field、review、regulatory；其他技术主题按实际设计说明证据类型和适用边界。

分别判断研究活跃度、证据强度、技术成熟度、商业可得性和现场采用度。主动寻找反证并记录冲突。保留趋势、显著性和效果强度，不能把上升趋势改成显著提升，也不能把单一研究改成普遍效果。

## 公司与产品状态

- `none`：正文不提公司观点或产品，默认选择。
- `company-perspective`：明确标记为当前品牌观点，与独立证据分开。
- `product-connection`：文章问题、证据与具体产品特征有直接逻辑链时才选用。

产品不是固定收尾。需要时放在文末并连接前文判断框架，不新增无台账支持的机制或效果。产品名称和编号逐字核对专属资料，不以相似产品替代。原料类别、设备原理或同系列研究不能自动证明特定产品的效果、安全、剂量、合规或优越性。

## 人工审核与资料保护

科学、法规、产品、公司、比较、最高级、剂量、定量、效果和品牌主张均需人工审核。使用公开资料也不豁免。目标市场改变时重新核对该市场的法规与生产条件。

用户输入和输出只留在用户选择的工作区，不上传、不加入技能包、不提交到公共仓库。不需要账户、密码或 API 密钥；若来源包含凭据、客户身份或未获公开许可的数据，使用脱敏摘要并保留审核限制，不直接转载。

本流程只准备待审稿，不做兽医诊断或配方计算，不执行发布、发帖、排期或知识库写入。
