# 人工审核清单

- [ ] Primary reader、Decision、Central thesis 和编辑模式一致。
- [ ] brief、证据矩阵、台账和正文已记录相关物种与生产阶段，跨物种证据的用途、外推链条和不确定性已说明。
- [ ] 检索日志只记录实际访问的来源，包含纳排标准、反证检索和限制。
- [ ] 证据矩阵记录实验单位、样本量、结局、局限、资金或利益冲突以及更正或撤稿检查。
- [ ] 已分别判断 Research activity、Evidence strength、Technology maturity、Commercial availability 和 Field adoption。
- [ ] 每项科学、法规、产品、公司、比较、最高级、剂量、定量和品牌主张都有台账行。
- [ ] 已打开来源定位，主张没有超出对象、条件、时间、研究设计和不确定性。
- [ ] 所有来源均保留 `review-required`，用户提供的品牌名称与主营产品没有被当作功效或合规证据。
- [ ] 用户资料、外部网页和范文均未被当作直接公开批准。
- [ ] 重要反证与冲突已经呈现，或明确记录未找到及检索限制。
- [ ] 更正或撤稿检查的“未发现”没有被写成绝对保证。
- [ ] 目标市场可迁移性已检查物种、阶段、日粮、管理、气候、经济性和法规。
- [ ] 产品连接状态为 none、company-perspective 或 product-connection，且公司观点与独立证据分开。
- [ ] 产品名称和编号已逐字核对产品专属来源，没有用相似产品替代。
- [ ] 趋势、显著性和效果强度没有被升级表述。
- [ ] 产品配方、效果、可用性、剂量和品牌表达已完成人工审核。
- [ ] 适用的科学与法规主张已完成人工审核。
- [ ] 文章状态为 `review` 或完成人工审核后的 `final`，确定性审计已通过。
- [ ] 发布仍是独立人工动作，未执行发帖、发布、排期或知识库写入。
