# 证据台账

每个可外部核验的主张占一行，七个字段均不能为空。列名必须保留英文，供确定性审计使用。

- `Source class`：`user_document` 或 `external_url`
- `Public-use decision`：`review-required` 或 `do-not-use`
- `Verification state`：只能为 `verified`
- `Support type`：`direct-evidence` 或 `inference`

范文只提供风格，不能进入本表。审计前删除所有 `do-not-use` 行。
Reviewer note 应关联 Evidence ID，并记录资金或利益冲突、更正或撤稿检查和关键适用边界。
